# 팀 작업 가이드 (GitHub Desktop)

## 처음 한 번
1. GitHub Desktop → File → Clone repository → `AxiA-AixA/axia` → Clone
2. Repository → Open in Visual Studio Code

## 매번 작업할 때
1. 시작 전: 위쪽 **Fetch origin** → **Pull origin** (상대가 올린 것 받기)
2. VS Code에서 고치고 저장
3. GitHub Desktop 왼쪽 아래에 한 줄 설명 쓰고 **Commit to main**
4. **Push origin**

## 폴더
| 폴더 | 뭐예요 |
|---|---|
| `prototype/` | Axia 시제품 (앱 + Chrome 확장). 태깅 엔진 `axia_tagger.py`는 여기 한 곳에만 있어요 |
| `tag-lab/` | 태그 규칙 시험·검토 작업대 (Test 3) |
| `tools/bench/` | 터미널용 측정 스크립트 (Test 3·4) |
