# Axia 시제품 v0.2

웹에서 본 이미지를 **우클릭 → Axia로 보내기** 하면 내 컴퓨터의 Axia 보관함에 저장되고, AI가 분야·태그·그룹을 붙여요.
지금까지 한 테스트(인스타 수집, 플랫폼 가져오기, Tag Lab 태깅 엔진, 썸네일 바로 저장)를 하나로 묶은 시험용 제품이에요.

## 구성

| 폴더·파일 | 역할 |
|---|---|
| `Axia-실행-Windows.bat` / `Axia-실행-Mac.command` | Axia 앱 켜기 (브라우저에 http://localhost:8770 이 열림) |
| `extension/` | Chrome 확장 "Axia로 보내기" |
| `axia_data/` | 내 보관함 (이미지, 목록, 설정, 태그 규칙). 처음 켜면 생겨요 |
| `axia_tagger.py` | 태깅 엔진 (Tag Lab과 같은 것 + 모델 자동 대체) |

## 1. 앱 켜기

- **Windows**: `Axia-실행-Windows.bat` 더블클릭. 처음 한 번 이미지 축소 도구(Pillow)를 자동 설치해요.
- **Mac**: `Axia-실행-Mac.command` 우클릭 → 열기.
- 검은 창이 켜져 있는 동안만 Axia가 동작해요. Tag Lab(8765)과 포트가 달라서 같이 켜도 돼요.

## 2. 확장 프로그램 설치 (처음 한 번)

1. Chrome 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더의 `extension` 폴더 선택
3. 퍼즐 아이콘 → "Axia로 보내기" 옆 핀 눌러 고정

## 3. AI 설정 (처음 한 번)

앱 화면 오른쪽 위 **설정** → API 키 입력 → 저장.
- 위에서부터 차례로 써요: `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite` → `claude-haiku-5-5` → `gpt-5.4-nano`
- 앞 모델이 붐비면(503)·한도에 걸리면(429)·없어졌으면(404) 다음 모델로 자동으로 넘어가요. 키가 없는 회사는 건너뛰어요.
- 키를 저장하면 실패했던 이미지를 자동으로 다시 분석해요.

## 4. 보내는 방법

| 어디서 | 어떻게 |
|---|---|
| 아무 웹페이지 이미지 | 이미지 위 우클릭 → **Axia로 보내기** |
| 인스타그램 게시물 | 사진 위 우클릭 → **Axia로 보내기** (투명한 막이 덮여 있어도 아래 사진을 찾아요) |
| 핀터레스트 핀 | 핀 이미지 우클릭 → **Axia로 보내기** |
| 핀터레스트 보드 전체 | 보드 페이지에서 우클릭 → **이 Pinterest 보드 전체를 Axia로 보내기** (또는 확장 아이콘 → 보드 전체 보내기). 끝까지 스크롤하며 최대 500핀. 아래쪽 "추천 핀"은 빼요 |
| 링크만 있을 때 | Axia 화면 위 칸에 붙여넣기 (핀 링크, pin.it 공유 링크, 이미지 주소, 일반 페이지). 인스타 저장함 링크는 로그인이 필요해서 안 돼요 → 위 방법으로 |
| 내 컴퓨터 파일 | Axia 화면에 끌어다 놓기 / 파일 올리기 |
| 인스타 저장함 통째로 | Chrome에서 저장함의 **모든 게시물** 또는 원하는 **컬렉션**을 열고 → 확장 아이콘 → **저장함 전체 보내기** (또는 페이지 우클릭). 탭을 화면에 띄워 두세요 |
| 인스타 새로 저장한 것만 | 같은 페이지에서 **새로 저장한 것만 보내기**. 이미 있는 게시물이 50개 연속 나오면 멈춰요 |
| 예전 수집 JSON | 인스타 수집 확장(v0.2) JSON → Axia 화면 **인스타 JSON** (수집 후 4일 안에) |

같은 이미지는 한 번만 저장해요(내용이 같은지 비교).

## 5. Tag Lab에서 다듬은 규칙 쓰기

Tag Lab의 `lab_data/court/court_vN.json`(가장 좋았던 버전)을 복사해서 이 폴더의 `axia_data/court.json`에 덮어쓰면, 다음부터 들어오는 이미지에 그 규칙이 적용돼요.
이미 있는 이미지에 다시 적용하려면 설정 → **실패한 것 다시 분석** 대신 이미지마다 **다시 분석**(전체 재분석 버튼은 다음 버전에).

## 알려진 한계 (시제품)

- 내 컴퓨터 안에서만 동작해요(계정·동기화·공유 없음). 실제 서비스는 이 구조를 서버로 옮기는 단계예요.
- 핀터레스트 보드 링크만 붙여넣으면 공개 보드의 최근 핀 일부만(RSS) 가져와요. 전체는 확장 프로그램으로.
- 인스타 게시물 링크만 붙여넣는 건 로그인 벽 때문에 실패할 수 있어요. 게시물에서 우클릭으로 보내세요.
- 확장 프로그램은 개발자 모드 설치예요. 쉬운 설치(웹 스토어)는 정식 버전에서.
- 그래프 보기는 한 번에 최대 600장까지 그려요. 더 많으면 필터로 좁혀서 보세요.
