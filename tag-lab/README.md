# Axia Tag Lab (Test 3 작업대)

AI가 레퍼런스 이미지에 **분야·태그·그룹 이름**을 붙이게 하고, 사람이 검토하고, 태그 규칙집(Court)을 고쳐서 다시 돌리는 도구예요.

이 도구는 AI를 새로 "학습"시키지 않아요. 이미 있는 AI 모델에게 우리 팀의 **태그 규칙집**을 주고 그대로 따르게 해요.
"학습"에 해당하는 건 사람이 결과를 보고 규칙집을 고치는 일이에요. 그래서 비용이 거의 안 들고, 고친 내용이 바로 반영되고, 실제 서비스에 그대로 옮길 수 있어요.

## 켜기

- **Mac**: `실행-Mac.command` 더블클릭 (처음엔 우클릭 → 열기). 또는 터미널에서 `python3 lab.py`
- **Windows**: `실행-Windows.bat` 더블클릭. Python이 없으면 python.org에서 설치(설치 화면에서 "Add python.exe to PATH" 체크)

브라우저에 `http://localhost:8765` 가 열려요. 끄려면 검은 창에서 Ctrl+C 또는 창 닫기.
추가 설치는 필요 없어요. (Pillow가 있으면 이미지 축소에 쓰고, 없으면 Mac 기본 도구나 원본을 써요.)

이미지 폴더는 자동으로 찾아요: 이 폴더 옆, `다운로드`, `바탕화면` 순서로 `samples` 또는 `axia-test3` 폴더. 화면의 "이미지 폴더"에서 경로를 바꿀 수도 있어요.
**하위 폴더 이름이 곧 분야(정답)예요** (예: `samples/3d`, `samples/Typography`, `samples/painting`, `samples/Graphic`, `samples/photo`). 한국어 폴더 이름(영상, 3D, 편집디자인…)도 돼요. `package` 폴더는 기본으로 빼고 돌려요(`--skip` 으로 바꿀 수 있음).

## 순서

1. **이미지** 탭: 분야 폴더마다 10장씩 들어 있는지 확인 (드라이브에서 받은 samples 폴더면 이미 돼 있음)
2. **AI 돌리기** 탭: 회사·모델 고르고 API 키 입력 → 처음엔 "앞에서 N장만"에 5 넣고 시험 → 괜찮으면 전체 실행 (50장 × 3회 × 2방식 = 300건, Haiku 기준 약 $0.05, 10분 안팎)
3. **사람 검토** 탭: 태그마다 맞음/애매/틀림. "남은 태그 모두 맞음"을 누른 뒤 틀린 것만 고르면 빨라요. 최소 30장 이상
4. **결과** 탭: 분야 정확도 90%, 태그 일관성 80% 넘는지 확인. CSV로 받아 시트에 붙여넣기
5. **태그 규칙(Court)** 탭: 오른쪽 제안을 보고 뜻 적기·합치기·추가 → 새 버전으로 저장 → 2번으로 돌아가 그 버전으로 다시 실행 → 결과 탭에서 v1과 v2 비교

검토 기록은 "이미지 + 태그" 단위로 저장돼서, 규칙을 고쳐 다시 돌려도 이미 판정한 태그는 다시 안 봐도 돼요.

## 저장되는 곳

`lab_data/` 폴더 안에만 저장돼요.

- `court/court_v1.json, v2…` 태그 규칙집 버전들
- `runs/*.jsonl` 실행 기록 (이미지별 AI 답, 토큰, 시간)
- `reviews.json` 사람 검토 기록

결과를 Claude에게 보낼 때는 `lab_data` 폴더를 통째로 압축해서 보내면 돼요. API 키는 어디에도 저장되지 않아요.

## 실제 서비스로 옮길 때

| 파일 | 역할 | 서비스에서 |
|---|---|---|
| `axia_tagger.py` | 이미지 한 장 → 분야·태그·그룹 (`tag_image()`) | **그대로 사용**. 업로드/가져오기 직후 이 함수를 호출 |
| `lab_data/court/court_vN.json` | 팀이 확정한 태그 규칙집 | **그대로 사용**. 서비스의 "공통 태그 기준" 파일 |
| `lab.py`, `ui/` | 시험·검토용 작업대 | 내부 운영 도구로 계속 사용 (규칙 바꿀 때마다 시험) |
| `mock_model.py` | 가짜 AI (화면 시험용) | 안 씀 |
