분야별로 이미지 10장씩 넣기

이미지 폴더 안의 하위 폴더 이름이 곧 분야(정답)예요. 각 칸에 이미지를 끌어다 놓으면 그 폴더에 저장돼요. 그 분야라고 확신하는 이미지만 넣어 주세요. package 폴더는 기본으로 제외해요.

AI에게 태그 붙이게 하기

같은 이미지를 3번씩 보내서, 매번 같은 답이 나오는지(일관성)와 정답 분야를 맞히는지(정확도)를 재요. "둘 다"를 고르면 태그 목록에서 고르기와 자유 태그를 같이 돌려 비교해요.

API 키는 비밀번호와 같아요. 이 화면에 입력한 키는 이 컴퓨터의 Tag Lab 프로그램 메모리에만 있고, 프로그램을 끄면 사라져요. 채팅이나 문서에는 붙여넣지 마세요.

사람 검토

AI가 붙인 태그마다 맞음 / 애매 / 틀림을 눌러 주세요. 어떤 방식·몇 번째 실행의 태그인지는 일부러 숨겼어요(선입견 방지). 태그 중 하나는 AI가 붙이지 않은 태그를 섞어 둔 것이라, 이게 맞는 태그면 "AI가 놓친 태그"로 기록돼요.

왼쪽에서 이미지를 고르세요. AI를 한 번 이상 돌린 뒤에 검토할 수 있어요.

결과 비교

실행 한 번이 한 줄이에요. 태그 규칙을 고치고 다시 돌리면 줄이 늘어나니, 버전끼리 숫자가 좋아졌는지 비교하면 돼요. 통과 기준: 분야 정확도 90% 이상, 태그 일관성 80% 이상.

각 숫자의 뜻 (팀 공유용)
분야 정확도3번 중 가장 많이 나온 분야가 정답(폴더 이름, 또는 검토에서 고친 값)과 같은 이미지 비율
분야 흔들림 없음3번 모두 같은 분야를 말한 이미지 비율
태그 일관성같은 이미지에 대해 3번의 태그가 얼마나 겹치는지 평균(자카드 지수: 겹친 태그 수 ÷ 합친 태그 수)
그룹 이름 일치3번의 그룹 이름이 글자까지 똑같은 비율
태그 정확도사람 검토에서 맞음 ÷ (맞음 + 틀림). 애매는 빼고 계산. 검토 비율이 낮으면 아직 믿기 어려워요
상위 5개 쏠림가장 많이 쓰인 태그 5개가 전체 사용의 몇 %인지. 높으면 AI가 몇 개 태그만 돌려 쓰는 것
목록 밖 태그목록에서만 고르라고 했는데 목록에 없는 태그를 낸 비율(자동으로 버려짐)
1,000장 비용실제 사용된 토큰 × 모델 가격. 가짜 AI는 의미 없음
결과표 CSV로 받기 (시트에 붙여넣기용)

태그 규칙집 (Court)

AI가 고를 수 있는 태그 목록과 각 태그의 뜻이에요. 여기를 고치는 것이 이 도구에서의 "학습"이에요. 흔들리거나 자주 틀리는 태그에 뜻을 적거나, 겹치는 태그를 합치거나, 빠진 태그를 추가한 뒤 새 버전으로 저장하고 다시 돌려서 숫자를 비교하세요.
